# Guantian Huang Academic Homepage

Static GitHub Pages source for the academic homepage.

## Local preview

Use any static HTTP server from this folder, then open `http://127.0.0.1:4173`.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

## Publishing target

Create the public repository `GuantianHuangg.github.io`, commit these files to its default branch, and enable GitHub Pages from that branch. The published site URL will be `https://guantianhuangg.github.io/`.
